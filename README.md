# BudgetTracker
Budget Tracker A simple and efficient budget tracking application built with HTML, CSS, and JavaScript. It helps users manage income, expenses, and savings in one place with a clean and responsive interface.

## ✨ Features
Add and categorize income and expenses

View balance updates in real time

Track spending trends with charts or summaries

Responsive design for desktop and mobile

Data stored locally in the browser (no backend required)

## 🚀 How It Works
Users can input their daily transactions, assign categories (e.g., food, transport, bills), and instantly see how their budget changes. The app calculates totals and provides a clear overview of financial health.

## 🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

Storage: LocalStorage (browser-based)

Optional: Chart.js for visual graphs

## 📌 Usage
Clone the repository

Open index.html in your browser

Add income and expenses to start tracking

Monitor your balance and spending patterns
